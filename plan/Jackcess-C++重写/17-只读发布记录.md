## 6. NULL 复杂外键证据

- Access 2024 的 DAO（含 `dbSeeChanges`）、ADO、SQL 与数据表视图（Delete/Backspace/下拉/剪切）均无法把现有复杂单元改为 NULL；新建行即使不赋复杂列，Access 仍自动分配外键。
- 固定 JAR 公共 API 同样自动分配（探针 `JackcessComplexNullProbe.java`）。
- 派生语料由 `csv_test complex-null-fixture` 按行读取器 NULL-mask 语义清除首行 `multi-value-data` 位，生成 `build/fixtures/complex-null-v2007.accdb`（SHA-256 `4aa32c39…6731669`），不提交入库。
- 结果：C++ `csv_complex_null_export` 断言 NULL 单元、相邻外键与全表/投影 CSV；固定 JAR 29 表一致，`ExportUtil` 全表 CSV 内容逐字一致（仅 CRLF/LF 差异）。
