## 2. 冻结范围

- **纳入**：普通、未编码库的只读能力。Jet4 V2000/V2003 先放行，ACE V2007/V2010/V2016/V2019
  逐版本放行。目录、表列定义、行与投影、长值、属性、关系、保存查询定义、索引读取与按键查询；
  ACE 另含复杂值类型化读取和计算列已存结果。
- **不属于首期只读**：Jet3、Generic Jet4、MSISAM、编码/加密库、外部链接源解析、通用 OLE 流接口、
  表达式求值（计算列只读已存结果）、ACE 与 Jet4 的新增写入能力、PGeo。
- **放行口径**：每个版本要么全部必测项「通过」，要么保留缺口并阻止该版本放行；「明确拒绝」
  只用于计划允许拒绝的操作（如 ACE 读写打开）。

状态取值：**通过**（有可复现证据）、**明确拒绝**（按预期报错）、**部分**（有证据但有缺口）、
**待验证**（无证据或无语料）、**不在范围**。

## 5. 本次新增证据

1. **Jet4 数据语料**：`tools/validation/JackcessJet4DataFixture.java` 用固定 JAR 写
   `jet4-data-v2000/v2003.mdb`，补上了此前 Jet4 语料全部为空表的缺口。覆盖 NULL 与空值的区别、
   非 ASCII 与 UTF-16 代理对、9000 字符跨页 MEMO、更新后迁移到 overflow 的行、数值与日期边界、
   需要 JSON 转义的文本。
2. **`jet4_data_read_v2000/v2003`**：逐列断言 schema，逐值断言 6 行，验证顺序扫描、主键正/反序遍历、
   迁移行按键查找，并断言打开前后文件字节相同。
3. **ACE 只读不改文件**：`ace*` 五个用例增加前后字节比较，覆盖全部 5 个 ACCDB。
4. 固定 JAR 生成器在写完后立即用同一 JAR 回读并打印全部行；本次回读与 `rea-jackcess canonical`
   的 13 类值逐项一致，仅 GUID 文本风格不同（JAR 输出大写带花括号，C++ 输出小写带花括号）。
5. **Jet4 复合索引语料**：`tools/validation/JackcessJet4IndexFixture.java` 生成
   `jet4-index-v2000/v2003.mdb`，含唯一 ignore-nulls 复合 TEXT 键、两处 NULL 键位置、
   前缀相等的 `A`/`AA`、乱序插入，以及一列 9000 字节跨页 OLE。
   `jet4_index_read_v2000/v2003` 断言索引顺序与反向顺序、`EU` 前缀正反扫描、`[EU/A, US/A)` 区间、
   复合精确查找和 OLE 全量载荷，打开前后字节不变。
6. **NULL 键的实际语义**：固定 JAR 会把含 NULL 的键写入索引叶（NULL 排最前），并非跳过该行；
   同一个全 NULL 键重复出现时按重复键告警并只保留一条。矩阵与语料说明按此行为登记。
7. **ACE V2016 与额外 V2019 语料**：`tools/validation/JackcessAceFixture.java` 生成
   `ace-v2016.accdb`、`ace-v2019.accdb`，补上 V2016 无样本的缺口，并给出第二个 V2019 样本。
   `ace_extra_read_v2016/v2019` 逐值断言全部行与文件字节不变。
8. **`MSysResources.Data` 类型映射缺口已复现并修复**：该列是 `COMPLEX_TYPE`（0x12），固定 JAR
   返回 `ComplexValueForeignKey`（数值 1）。此前 `Table::rows()` 返回 `UnsupportedValue`，canonical
   报告 “Canonical type mapping is not defined”。现在值按 4 字节外键解码为 LONG，canonical 类型
   名为 `complex`；系统表读取不再有诊断。

## 7. 缺口清单

| 缺口 | 影响 | 取得途径 |
|---|---|---|
| `MDB_REFERENCE_DIR` 与 canonical 比较器缺失 | 无法做公共语料 48 值对照与逐字段 diff | 恢复计划总览所指本地目录，或按[验收门槛](02-验收与发布门槛.md)重建比较器并记录来源 |
| 无独立来源 Jet4 真实库 | P1 Jet4 只读放行的核心证据不足 | 客户样本或 Access 生成库；保留哈希与生成步骤 |
| V2016 与额外 V2019 仅有生成语料 | `AR-08`/`AR-09` 缺独立来源证据 | 用 Access 2016/2019 建库或上游测试资源，固定 JAR 回读 |
| 无非标记 LONG 外键真实样本 | `AR-10` 仅合成证据 | 构造非标记关联的 ACE 样本 |
| 无复合 MEMO 键与重复键语料 | 复合 MEMO 键截断与唯一冲突未验证 | 在 `JackcessJet4IndexFixture` 追加 MEMO 键表与重复键探测 |
| 无超大 BINARY 语料 | BINARY 上限附近的读取未验证 | 追加接近 255 字节上限的 BINARY 列 |
| 未注册 `real_sample` | 真实库路径无回归 | 提供 `test_data_only_read/test_mdb.mdb` 并固定哈希 |
| 无原生 Linux 双架构环境 | `XR-04`/`XR-05` 阻塞放行 | 目标平台构建机 |
| 无性能语料与门槛 | `XR-06` 未定 | 冻结矩阵时确定资源门槛并造 20 万行/1 GB 样本 |
| 无损坏语料集 | `JR-16` 仅合成用例 | 固定样例：截断、坏页、坏长值链、未完成写日志 |
