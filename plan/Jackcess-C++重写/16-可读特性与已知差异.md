# 可读特性与已知差异（R6.2 发布结论）

> **状态：缩减范围发布。** 本文整理 `rea-jackcess` 当前可读能力、明确拒绝行为、相对固定 Jackcess 5.2.0 的已知差异及运行依赖。发布承诺仅覆盖 §7 列出的已验能力；真实 AR-10 与加密页解密仍标为待验证，不作为本次承诺。证据与语料见[只读发布记录](17-只读发布记录.md)。

## 1. 文档定位与当前状态

### 2.1 PGeo 原始载荷读取

- 独立目标 `rea_jackcess::pgeo`，**仅依赖核心公开 API**，不引入 GDAL/libmdb 依赖。
- 支持两种 PGeo 目录布局：
  - `GDB_Items` + `GDB_ItemTypes`（较旧，如固定样本 `test_mdb.mdb` 与 GDAL v3.10.0 公开语料）；
  - `GDB_FeatureClasses` + `GDB_ObjectClasses`（较新 Esri 目录，如本地实例 `test_mdb_2.mdb`）。
- 已验证语料：固定样本（17 图层/30 要素）、本地真实库 `test_mdb_2.mdb`（2 图层/2387 要素）、GDAL 公开样本（3 图层/33 要素，有效 SRS）；三者均按 OBJECTID 与固定 JAR 对照图层、属性值与 SHAPE 字节。
- 按图层返回：图层名、物理表名、OBJECTID 字段、几何字段、`ShapeType`、`HasZ/HasM`、属性列的 `ColumnInfo`、SRID 与可用的 `SRTEXT`（原样返回，不解释为 WKT/EPSG）。
- 逐要素返回 OBJECTID、类型化属性与**原始 SHAPE 字节**。**几何解码、解压和空间索引构建由下游处理**，本项目不做。

## 3. 明确拒绝 / 不支持的行为

以下情形显式报错或保留原始字节，**不会静默返回错误数据**：

| 情形 | 行为 |
|---|---|
| ACE 库以读写方式打开 | `unsupported_operation`（复杂列写入等 ACE 写入未实现） |
| 编码库未提供 `PageCodec` | `unsupported_operation`，不返回乱码；编码键非零、ACE `EncryptionInfo` 非空或 MSISAM 容器均按编码库处理；页 0 始终原样（头部可读） |
| 未映射的列类型 | 保留为 `UnsupportedValue{description, raw_bytes}`，并记入 `errors` |
| CSV 导出未知标量类型列 | `unsupported_operation`；复杂列按十进制外键导出（见 §4） |
| 查询执行 / 表达式求值 | 未实现（仅读取保存查询的目录与 SQL 文本） |
| 几何解码 / PGeo 样本克隆 | 未实现（超出原始载荷范围） |
| MSISAM 容器 / 特定格式写入 | 未实现，显式拒绝 |

`DatabaseError` 携带稳定错误码与尽可能完整的文件/页/表/行/列上下文：

| 错误码 | 含义 |
|---|---|
| `io_error` | 文件 I/O 失败 |
| `truncated_file` | 文件或缓冲被截断 |
| `unsupported_version` | 版本头不被支持 |
| `corrupted_file` | 结构损坏（长度、偏移、引用、校验等） |
| `page_out_of_range` | 页号越界 |
| `unsupported_operation` | 该操作/格式当前不支持 |
| `constraint_violation` | 写入会破坏文件已声明的约束（写入路径） |

## 4. 已知差异 / 刻意取舍（相对固定 Jackcess 5.2.0）

| 主题 | 行为 |
|---|---|
| BOOLEAN | 存于行尾 NULL mask 位；Jet4 无法区分 NULL 与 FALSE，写 NULL 读回为 FALSE |
| 日期 | 以 Java `LocalDateTime.toString()` 形式（ISO-8601 文本）暴露；越界 serial 以 `DateOutOfRangeValue` / `$dateOutOfRange` 表示，保留原始 serial |
| MONEY / NUMERIC | 用四位小数的精确十进制 `DecimalValue`（不经二进制浮点） |
| 文本 | 文件内 UTF-16LE，API 暴露为 UTF-8 `std::string` |
| 索引文本键 | Jet4：先截到 255 个 UTF-16 单元；完整键 >510 字节按 Jackcess 计算 CRC-16；LCID 1049/1055/1058 version 0 回退 General Legacy。Jet3：索引扫描可用，但按文本键精确查找尚未实现，返回 `unsupported_operation` |
| 复杂列 CSV | 导出十进制 `ComplexValueForeignKey`，不展开多值/附件/版本历史的 flat-table 值；不可导入 |
| CSV 文本形式 | 对齐 `ExportUtil`：空字段=NULL、true/false、MONEY 四位小数、Java 浮点文本、带花括号大写 GUID、大写十六进制按 4 字节分组 |
| 计算列 | 只按 `ResultType` 暴露逻辑类型并读取已存结果，**不求值公式** |
| 扩展日期存储变体 | 只解码 Access 标准 42 字节布局（19 位天数 `:` 12 位秒 + 7 位 100ns + 尾标）。DAO 写出的“第二形态”（15 位天数、19 位 100ns 计数及额外尾字节）按非法编码拒绝；固定 JAR 会把该布局误当标准布局解析出越界日期。相关公开样本 `ace-extended-date-table-type.accdb`、`ace-second-form-foreign-key.accdb` 只作差异探测，不计入发布对照 |
| 只读并发 | 读写句柄持有 OS advisory 排他锁；`.reajournal` 为崩溃恢复日志，**不是数据库事务** |
| PGeo SHAPE | NULL SHAPE = `nullopt`；零长度 SHAPE = 已启用的空字节向量 |

## 5. 运行依赖

- **核心库**：ASCII 平台仅依赖 zlib；macOS 额外用系统 `libc++`/`libSystem`。**无 JVM、GDAL、libmdb 依赖**。
- **PGeo 适配层**：仅用核心公开 API，不引入额外第三方库。
- **构建**：CMake ≥ 3.16、C++17 编译器、zlib。
- **CLI** `rea-jackcess`：`--help`、`--version`、`create <db> <v2000|v2003>`、`inspect <db>`、`canonical <db> [--code-page <n>]`、`export <db> <table> <csv> [--header]`、`import <db> <table> <csv> [--header]`。

## 7. 发布结论（缩减范围）

- **通用 MDB/ACCDB 核心读取：放行，附待验证清单。** 已验范围包括 Jet3 表/行/索引/保存查询与 936/932/1251 代码页解码（真实 Access 97 936/932 库与固定 JAR 逐表一致）、Jet4 V2000/V2003 与 Generic Jet4 的目录/schema/行/索引/长值/属性/关系/查询/链接表、ACE V2007/V2010/V2016/V2019 的普通表与复杂列只读、CSV 导入导出（含十进制复杂外键与 NULL 单元），以及独立 ACE V2016/V2019 语料。30 份可读文件的 canonical 与固定 Jackcess 5.2.0 JAR 全表一致；所有输入样本对照前后哈希不变。真实 AR-10 与加密页解密未验证，**不承诺**这些场景的兼容性；扩展日期“第二形态”按非法编码拒绝（见 §4）。真实加密库的编码检测与无 codec 拒绝已验。
- **PGeo 原始载荷：放行。** 两种目录布局、固定样本、本地真实库与 GDAL 公开语料均按图层/OBJECTID/属性/SHAPE 与固定 JAR 一致；SRS 原样返回，不做 WKT/EPSG 解释。几何解码、解压、空间索引与样本克隆不在本次范围。
- 发布证据：[只读发布记录](17-只读发布记录.md) 关联构建提交、产物哈希、CTest 结果、JAR/依赖哈希、语料清单与逐表结果。平台证据来自 Windows 开发验证与 Linux x86_64/ARM64 CI：候选 `bca6f3b` 的 run [`46119820583`](https://github.com/EdgarLQS/rea-jackcess/actions/runs/46119820583) 与含公开语料收口代码 `4304a3c` 的 `9a8d56d` run [`46139163622`](https://github.com/EdgarLQS/rea-jackcess/actions/runs/46139163622) 五行作业（含 sanitizer 与 perf）均全部 `success`。
