## 2026-11-20：C++ V2000 无索引表 overflow 行增长基线（初版）

以下结果记录行缩短实现之前的增长用例；当时缩短操作被拒绝。当前缩短实现和复测见下一节。

本地 C++ fixture 从固定模板新建 V2000 数据库，向无索引表写入 TEXT/BINARY 行，再依次把 TEXT 从 1 字符增长到 127、再增长到 255 字符，触发 inline-to-overflow 和 overflow-to-overflow 更新；随后执行等编码长度更新。CTest 另验证逻辑 RowId 与表行数不变、关闭重开后仍可读取，以及缩短更新被拒绝且文件字节不变。最终 fixture 大小为 110,592 字节，SHA-256 为 `9a9c0360e3c056ea286ca46c6c880b5c76f4497a065ac2f449a227483a47863b`。

固定 Jackcess 5.2.0 JAR 独立打开该 C++ 文件，检查预期 schema、4 行及重开后的最终值：255 个 `r` 字符、BINARY `{1,2,3}`、Unicode `🚀`、空值和 NULL。逻辑 RowId 稳定、行数保持、缩短拒绝且文件字节不变由定向 CTest 检查（`database_create` 为 1/1 通过）。此结果只验证合成 V2000 无索引表和受支持的单页行，不覆盖已有索引库写入、长值、Usage Map 扩展、其他格式或完整 P2 验收。

初版工具命令已随 fixture 增加缩短场景而过期；当前增长与缩短的可复现命令见下一节。此处哈希只标识初版运行产物。
