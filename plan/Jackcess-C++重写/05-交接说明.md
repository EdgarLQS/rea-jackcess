## 6. 接手注意（踩过的坑）

1. **回滚是进程内内存记录**。写盘批次失败会回滚到操作前（级联、关系创建共用 `context.undo`），但进程崩溃无法恢复；不要把它当数据库事务。
2. **写句柄独占文件**。测试里不要同时开两个 `read_write` 句柄；需要复核先关句柄或开 `read_only`。
3. **写互斥是 `std::recursive_mutex`**：级联会重入行写入入口，退回 `std::mutex` 会自锁。
4. **定义页布局是定点的**：`[header 63][物理索引行数块 12×n][列定义 25×n][列名][物理块 52×n][逻辑块 28×n][索引名][长值映射][0xFF 0xFF]`。新增描述块要插在现有逻辑块**之后**、名字追加在现有名字**之后**；插错位置会让名字与描述整体错位。需同步 `definition_size`(offset 8)、`logical_index_count`(47)、空闲空间(2)。
5. **公开视图有缓存**。改定义页后必须重读并刷新 `DatabaseState.indexes`，否则 `Table::indexes()` 还是旧值（`create_relationship`、`add_index` 都已处理）。
6. **拒绝码要区分**：数据违反约束用 `constraint_violation`，功能未实现用 `unsupported_operation`；测试断言具体码。
7. **`Value` 没有全序 `operator==`**（Decimal/DateTime/GUID 等未定义比较），测试里用 `std::get_if` 比较具体类型。
8. **样本是二进制资产**：改生成器或替换样本就要重算哈希、更新两处文档并说明可复现条件。
9. **Jackcess 语义要实测**：部分 NULL 外键 Jackcess 也拒绝（不是 SQL MATCH SIMPLE）；降序外键索引 Jackcess/Access 都不会生成；DDL/passthrough 的 SQL 带尾随 NUL。
10. **查询测试是逐字节断言**：改 `to_sql()` 的空白或引号风格都会让 `saved_query_*` 失败——这正是不允许"顺手美化" SQL 的原因。
11. **CSV 文本也是基线契约**：MONEY 恒四位小数、浮点按 Java 规则、BLOB 每 4 字节多一个空格、GUID 带花括号大写、日期按 Java `LocalDateTime.toString()`；改格式会让 `csv_round_trip` / `date_time_*` 失败，也会破坏与 Jackcess 的互换。
12. **写盘日志与写句柄绑定**：批次在首次改页前写 `<库>.reajournal`，`flush` 成功后删除；测试里模拟崩溃请用 `PageWriteUndo` + `PageFileWriter` 而不 flush。残留日志会让只读打开失败，这是预期行为。
13. **日期只有 SHORT_DATE_TIME**：固定 Jar 对 Jet4 建表直接拒绝 EXT_DATE_TIME，不要"顺手"加进去。

## 7. 建议的下一步（按依赖排序）

1. **属性语义层**：属性名查找已对齐 OpenJDK 21.0.12 的 Locale.ROOT 全大写规范化；Jet4 SINGLE/DOUBLE 默认值接受有限十进制与指数字面量，MONEY 默认值接受可精确编码的十进制/指数字面量；SHORT_DATE_TIME 默认值支持 `#M/D/YYYY#` 日期字面量；列级与表级校验均支持 SINGLE/DOUBLE 有限数值比较；MONEY 列级/表级校验使用精确十进制比较，列级也支持 `BETWEEN`；数值 `BETWEEN` 支持反向上下界。其他默认值、校验表达式和计算列语义仍需按固定基线补齐；完整表达式求值依赖 #9。
2. **链接解析差距**：补同源多表共享临时库、内存库/自定义临时目录选项。
3. **查询执行与表达式引擎**（按决策后置，待 SQL 能力重新排期）。
4. **ACE 复杂列读取**：固定 V2007/V2010 已能按父行读取 raw 与类型化复杂值，并解出附件文件载荷；非标记 LONG 外键回退已按固定版实现并做合成单测，仍需真实样本、异常 schema 检查和 ACE 版本扩展；ACE 写入另行实现和验收。
