1. **先做 R1.2–R1.4。** 核对 `72eb3b9` 对应的 GitHub Actions 作业；缺运行结果时，在原生 Linux x86_64 和 ARM64 按 R1 命令复现。先解决平台回归、语料缺失和 Sanitizer 失败，再归档性能与产物。
